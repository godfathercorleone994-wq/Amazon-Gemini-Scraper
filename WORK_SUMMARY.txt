HOW TO DEPLOY (QUICK VERSION)
================================================================================

1. SET UP MONGODB ATLAS (5 min)
   - Create free cluster
   - Get connection string
   
2. GET GEMINI API KEY (2 min)
   - Visit https://makersuite.google.com/app/apikey
   - Create and copy API key
   
3. DEPLOY ON RENDER (3 min)
   - Create Web Service
   - Connect GitHub repo
   - Set build/start commands
   - Add environment variables
   
4. ADD REDIS (1 min)
   - Enable Render Redis addon
   
5. CONFIGURE ENVIRONMENT
   - Add MONGODB_ATLAS_URI
   - Add GEMINI_API_KEY
   - Generate SECRET_KEY
   
6. WAIT FOR BUILD (8-10 min)
   - Monitor logs
   - First build takes longer
   
7. TEST API
   - Visit /api/v1/docs
   - Test health endpoint
